## 使用方法

1. 打开 Cheat Engine 7.x。
2. 启动游戏，并在 Cheat Engine 中附加 `NFS11Remastered.exe`。
3. 打开对应的 `.CT` 文件。
4. 按需勾选脚本条目前面的复选框。

## 注意事项

- 这些脚本面向单人模式，不建议在多人联机中使用。
- 冻结所有 AI 驾驶指令（单人模式）：必须在比赛开始之前开启；比赛开始后再开启可能不生效。
- 比赛计时归零：不建议一直开启，建议只在有时间限制的关卡使用。看到计时归零后请立即关闭脚本；一直开启可能导致通关结算判定异常，从而无法获得金牌。
- 游戏更新或不同版本可能导致 AOB 签名、偏移地址失效。
- 比赛计时和装备数量相关脚本会持续写入内存，使用前建议备份存档。
- 如果某一条脚本无法启用，请确认游戏版本与 CT 版本一致。

## 脚本原理

- **冻结所有 AI 驾驶指令（单人模式）**：定位 AI 驾驶相关函数的指令签名，启用时把入口指令替换为 `ret`，让 AI 驾驶逻辑直接返回。
- **比赛计时归零（玩家）**：使用 Lua 定时器读取计时管理器，监控多个候选计时字段；发现字段继续增长时写回 `0`。
- **无限生命（玩家）**：拦截玩家车辆损伤读取函数，启用时把损伤值写为 `0` 后返回。
- **无限氮气（玩家）**：拦截氮气写回指令，并把玩家氮气值持续写为 `100.0`。
- **武器无冷却**：定时扫描当前装备组的冷却数组，把未满的冷却值写回 `1.0`。
- **无限装备使用次数（玩家）**：定时把当前装备组的 12 个装备计数槽写为 `9`，并在启用后保持补满。

以上脚本只修改游戏运行内存，不会修改游戏文件或存档。其中计时归零脚本会持续压住计时值，推荐流程是：仅在有时间限制的关卡使用 → 开启脚本 → 看到计时归零 → 立即关闭脚本。
