# Need for Speed™ Hot Pursuit Remastered《极品飞车：热力追踪》重制版 中文版 Cheat Table

适用于 **Need for Speed™ Hot Pursuit Remastered**（**《极品飞车：热力追踪》重制版**）的 Cheat Engine 表格中文版。原脚本逻辑保持不变，仅翻译了 Cheat Engine 中显示的条目名称。

## 功能

| 中文条目 | 英文条目 |
| --- | --- |
| 冻结所有 AI 驾驶指令（单人模式） | Freeze all AI driving commands (single-player) |
| 比赛计时归零（玩家） | Race Timer Zero (Player) |
| 无限生命（玩家） | Infinite Health (Player) |
| 无限氮气（玩家） | Infinite Nitrous (Player) |
| 武器无冷却（玩家） | No Weapon Cooldown (Player) |
| 无限装备使用次数（玩家） | Infinite Weapon Uses (Player) |

## 文件

- `Need for Speed Hot Pursuit Remastered - 中文版.CT`：中文条目版本
- `Need for Speed Hot Pursuit Remastered.CT`：原始英文版本，保留用于对照

## 使用方法

1. 打开 Cheat Engine 7.x。
2. 启动游戏，并在 Cheat Engine 中附加 `NFS11Remastered.exe`。
3. 打开对应的 `.CT` 文件。
4. 按需勾选脚本条目前面的复选框。

## 注意事项

- 这些脚本面向单人模式，不建议在多人联机中使用。
- 游戏更新或不同版本可能导致 AOB 签名、偏移地址失效。
- 比赛计时和装备数量相关脚本会持续写入内存，使用前建议备份存档。
- 如果某一条脚本无法启用，请确认游戏版本与 CT 版本一致。

## 说明

本仓库是把现有 Cheat Table 制作成中文版本的存档，脚本功能与原表保持一致。
